# 开发日志 2026-10-21

## Homework01 列表倒序遍历 · 2026-10-21 08:50

**需求**
`src/com/collections_/Homework01.java` 里原本用 for-each 正序打印 `ArrayList` 中的 `News` 对象，需求是改成倒序遍历输出。

**改动**
- `src/com/collections_/Homework01.java`（仅 main 中的遍历循环，第 18-20 行）
  - 删掉 `for(Object o:list)` 正序 for-each
  - 改成按下标从尾到头的普通 for 循环：`for (int i = list.size() - 1; i >= 0; i--)` + `list.get(i)`

**设计原因 / 权衡**
- 选用「下标倒序 for 循环」而不是其他倒序写法，理由：
  - 不修改原列表内容/顺序（对比 `Collections.reverse(list)`：那个会改变 list 自身顺序，属副作用，这里只是想换个打印顺序）；
  - `ArrayList` 支持随机访问 `get(i)`，倒序按下标走是 O(1) 取元素，最直观；
  - 对照方案 `ListIterator` 从尾部 `previous()` 也行，但对当前只有 2 个元素的练习题来说反而绕，且 for-each/`Iterator` 本身不支持逆向，必须换 API，学习曲线上不如下标循环清晰。
- 列表是原始类型 `ArrayList`（未写泛型），`list.get(i)` 返回 `Object`，直接 `System.out.println` 仍走 `News.toString()`（只打印 title），与原逻辑一致，因此没有顺手改泛型——避免和本次「倒序」需求混在一起。

**验证**
- `javac -encoding UTF-8 -d out src/com/collections_/Homework01.java && java -Dfile.encoding=UTF-8 -cp out com.collections_.Homework01`
- 输出顺序为：先「男子突然想起2个月前钓的鱼还在网兜里…」（news02），后「新冠确诊病例超千万…」（news01），确认倒序生效；编译仅有原始类型的 unchecked 警告（`@SuppressWarnings("all")` 打在类上不影响编译器提示，属预期）。
